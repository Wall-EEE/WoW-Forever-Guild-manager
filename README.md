# WoW Forever Guild Manager

A Discord-first guild and guest raid management app prototype built with Next.js, TypeScript and Tailwind CSS.

## Run locally

Requires Node.js 20.9+.

```powershell
npm install
npm run dev
```

Open http://localhost:3000.

## Status

This initial milestone uses demo data only. Discord OAuth, guild/guest permissions, character management, database persistence and real raid signups are **not implemented yet**.

## Roadmap

1. PostgreSQL/Supabase schema for players, characters, memberships and guest approval.
2. Discord OAuth and authenticated profiles.
3. Server-enforced roles and permissions.
4. Shared raid calendar, signups and roster builder.

This is an unofficial fan project.
